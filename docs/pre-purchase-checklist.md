# ChatGPT 代充前的 7 项核验：付钱之前逐条对一遍

**最后核实：2026-09-29** · [← 返回总览](../README.md)

这 7 项都能在付款前自己核对，不需要相信任何人的口头承诺。每项写了为什么要查、怎么查、不满足时怎么办。任何一项答不上来，就先不付款。

> 利益相关：本仓库由 KAI · 开gptAI 团队维护，KAI 本身就是第三方开通服务。下面的每一项，也请拿来核对 KAI。

## 开始之前：先确认两件和渠道无关的事

- **你是否在 OpenAI 支持的国家或地区。** OpenAI 的《ChatGPT Supported Countries》写明，在列表以外的地区访问或提供访问，可能导致账号被封禁或停用。付款方式解决不了这一点，本仓库也不提供任何规避方法。
- **你到底要开通哪个账号。** 记下它的登录邮箱和登录方式（Google、Apple、Microsoft 或邮箱密码）。用公司邮箱注册的账号，可能归属于公司的工作区，个人开通会员前先确认。

## 1. 账号归属：会员开到你自己的账号上

**为什么查**：会员开在你的账号上，聊天记录、记忆、上传的文件都归你；拿到一个别人注册的账号（成品号）或多人共用的账号（共享号），原注册人随时可以改密码收回，你的聊天内容对别人可见，而且和 OpenAI 的账号共享政策明确冲突。

**怎么查**：

- 看商品页写的是“为你的账号开通”，还是“发货账号”“独享号”“拼车”。
- 问清楚开通方式：是在你的账号上订阅，还是把你的邮箱邀请进某个工作区（那是工作区席位，成员和账单由工作区所有者管理，不是你个人账号上的 Plus）。
- 把对方的回答截图保存。

**不满足时**：只要不是开到你自己长期控制的账号上，就不买。

## 2. 凭证边界：不给密码和验证码，Session 只在对方自有页面提交

**为什么查**：密码加验证码等于账号的全部控制权，对方可以改密码、改邮箱、关掉你的 MFA。Session 是登录状态，交出去的是有效期内的访问权（详见 [Session 是什么](what-is-session.md)）。

**怎么查**：

- 服务条款或帮助页是否写明“不索取密码和验证码”。
- 需要 Session 的服务，是否写明只在它自己的兑换页提交，兑换页的域名是什么。
- 客服有没有在聊天里要过任何凭证。

**不满足时**：对方要密码、任何一种验证码、恢复码或 API Key，立即停止。要你在聊天、邮件或工单里发 Session，也停止。

## 3. 收款主体：付给谁，和网站写的是不是同一家

**为什么查**：出问题时，你能追查的只有付款记录上的收款方。私聊发来的链接、个人收款码，收款方可能和网站没有关系。

**怎么查**：

- 网站页脚、服务条款里有没有写明运营主体。
- 只在网站下单页付款；付款成功页上的收款方名称，和网站写的运营主体对得上。
- 不点聊天里发来的临时付款链接，不扫个人收款码，不转账。

**不满足时**：收款方对不上，或者只能私下付款，就不买。

## 4. 订单记录：有订单号和状态时间线

**为什么查**：没有订单号，出了问题只能翻聊天记录，对方删号就无从追查。

**怎么查**：

- 下单后是否立即生成唯一订单号。
- 能不能在网站上随时查询订单状态（已支付、处理中、需要你操作、已完成、失败、退款中）。
- 关键节点有没有邮件或站内通知。

**不满足时**：没有订单号和查询入口的，不买。

## 5. Session 保存方式：写在隐私政策里

**为什么查**：Session 交出去以后，谁能看到、存多久、什么时候删除，决定了这次风险的持续时间。

**怎么查**：读隐私政策，找这几句话：

- Session 用于什么（只用于这一笔订单，还是还有其他用途）；
- 怎么保存（是否加密、谁能访问）；
- 什么时候删除（任务结束后、凭证过期后，还是没写）。

以书面政策为准，客服的口头说法不算。

**不满足时**：没有隐私政策，或者政策里完全没提 Session，就把这次开通当成“访问权交出去后不知道什么时候收回”，自己决定接不接受；接受的话，开通完成后务必[立刻收回](what-is-session.md#用完之后怎么收回)。

## 6. 退款条件写在页面上

**为什么查**：数字服务“开通成功后不适用无理由取消”很常见。付款前不知道条件，出了问题只能靠对方的态度。

**怎么查**：付款前在页面上找到这三件事的答案：

1. **什么情况能退？** 没开通成功算不算？开通后账号又被限制算不算？
2. **退到哪里？** 原路退回，还是退成平台余额或优惠券？
3. **多久核实、多久到账？** 有没有写明时间？

**不满足时**：退款条件只在聊天里说、页面上没有的，按“不能退”来估算风险。写“无条件包退”的，反而要警惕（见 [骗局 6](scam-patterns.md#6-承诺无条件保证成功无条件退款)）。

## 7. 表述是否诚实

**为什么查**：一个渠道怎么描述自己，能看出它会不会在别的地方也夸大。

**怎么查**，出现下面任何一种说法，都要打个问号：

- 自称与 OpenAI 有合作、获得许可，或者自称“OpenAI 指定渠道”；
- 承诺“不会被限制”“不影响账号”“保证成功”；
- 用户数、成功率、好评数没有出处；
- 价格明显低于正常水平，又说不清开通方式。

**不满足时**：能对“账号会不会被限制”作出承诺的只有 OpenAI。承诺做不到的事的渠道，在其他地方的说法也要打折看。

## 付钱前 5 分钟的顺序

1. 确认所在地区和要开通的账号。
2. 读商品页，确认开到你自己的账号上（第 1 项）。
3. 读服务条款和隐私政策：凭证边界、Session 保存方式、退款条件（第 2、5、6 项）。
4. 只在网站下单页付款，核对收款方（第 3 项）。
5. 保存订单号、付款截图、条款截图（第 4 项）。
