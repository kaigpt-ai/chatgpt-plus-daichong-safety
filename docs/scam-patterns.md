# ChatGPT 代充骗局：9 种常见手法与识别信号

**最后核实：2026-09-29** · [← 返回总览](../README.md)

下面 9 种手法都有一个共同点：让你在没有记录、没有退路的地方交出钱或账号访问权。每种写了识别信号、为什么危险、该怎么做。**出现任何一条，先停下来。**

> 利益相关：本仓库由 KAI · 开gptAI 团队维护，KAI 本身就是第三方开通服务。这些信号同样适用于 KAI；也有人会冒充 KAI 或其他服务方，见第 9 种。

|---|---|---|

| 2 | 索要密码或验证码 | “为了开通，需要你的密码 / 收到的验证码” |
| 3 | 共享号或成品号冒充开到你的账号 | “给你一个开好的号”“独享号” |

## 1. 私聊里发来的临时付款链接

**识别信号**：客服或“朋友介绍的人”在聊天里发来付款链接、个人收款码，或者让你转账，理由通常是“网站通道维护”“这样便宜一点”“走私人通道更快”。

**为什么危险**：钱付给了谁，和网站没有关系；没有订单号，出了问题无处追查。有的仿冒者会冒用真实服务方的名字和头像。

**该怎么做**：只在网站的下单页付款。付款成功页上的收款方名称要和网站写明的运营主体对得上。对方坚持私下付款的，结束对话。

## 2. 索要密码或验证码

**识别信号**：要你的 ChatGPT 密码、邮箱密码、邮箱或短信验证码、MFA 验证码、恢复码，或者说“待会儿会收到一个验证码，发给我”。

**为什么危险**：密码加验证码就是账号的全部控制权。对方可以改密码、改邮箱、关闭你的 MFA，把账号彻底拿走。“发验证码给我”是接管账号最常见的最后一步。

**该怎么做**：任何人、以任何理由要这些东西，都拒绝，包括自称客服的人。已经给出去的，立刻按 [账号异常处理](account-anomaly-recovery.md) 操作。OpenAI 帮助中心也提醒，不要向任何人提供密码或一次性验证码。

## 3. 用共享号或成品号冒充“开到你自己的账号”

**识别信号**：商品叫“独享号”“成品号”“拼车”“车位”，或者付款后收到一组别人的账号密码；价格往往明显更低。

**为什么危险**：

- 账号不属于你。原注册人或注册邮箱的持有人可以随时改密码、找回账号。
- 多人共用时，你的聊天记录、上传的文件对别人可见。
- OpenAI 的账号共享政策写明账号只供创建它的个人使用，共享账号和条款明确冲突，比“开到自己账号”的风险更直接。
- 会员到期或账号被收回时，你的记录一起丢失，无法迁移。

**该怎么做**：只给你自己长期控制的账号开通。如果已经在用共享号，不要在里面放任何隐私资料，重要对话及时导出。

## 4. 价格远低于正常水平，又说不清怎么开通

**识别信号**：价格明显低于 OpenAI 标价按汇率折算后的水平，问开通方式时含糊其辞。

**为什么危险**：低价通常意味着以下几种情况之一：共享号或成品号；把你拉进别人管理的工作区；用来路不明的付款方式开通，事后被撤销；或者根本不发货。这几种情况的账号归属和风险完全不同。

**该怎么做**：先问清是哪一种，把回答截图保存。说不清的，不买。需要比价时，看公开的第三方比价信息，别只凭聊天里的报价。

## 5. 自称与 OpenAI 有合作或获得许可

**识别信号**：“OpenAI 合作渠道”“指定服务商”“内部名额”“特批通道”，页面上还可能用 OpenAI 或 ChatGPT 的标志。

**为什么危险**：在 OpenAI 的公开页面上，找不到任何为个人用户代开会员的合作渠道。编造和平台的关系，是借平台的名义换你的信任；一个在这件事上说不实话的渠道，其他说法也要打折看。

**该怎么做**：看对方有没有写明“与 OpenAI 无隶属关系”这类声明。自称有合作的，要求给出 OpenAI 那边可以核对的公开来源；给不出来，就当作不实宣传。

## 6. 承诺无条件保证成功、无条件退款

**识别信号**：“保证成功”“不成功全额退”“不会被限制”“不影响账号”，而页面上找不到对应的书面条款。

**为什么危险**：账号会不会被限制，只有 OpenAI 能决定，第三方承诺不了。退款条件只在聊天里说、页面上没有，出了问题对方可以不认。

**该怎么做**：只认页面上写明的条款。靠谱的退款条款通常是有条件的，比如“因平台或履约原因确认无法开通的订单，核实后原路退款”。看到无条件承诺，把它当成风险信号，而不是安心的理由。

## 7. 要求在聊天、邮件或工单里发送 Session

**识别信号**：客服说“把这段内容复制给我”“截图发我”“发到邮箱里我们处理”。

**为什么危险**：Session 是账号的登录状态，在有效期内等于一个已登录的你（见 [Session 是什么](what-is-session.md)）。发在聊天、邮件或工单里，它会留在聊天记录和客服系统里，谁能看到、存多久都不可控，冒充客服的人也能拿到。

**该怎么做**：拒绝。需要 Session 的服务方，应当只让你在它自己的兑换页提交，并在隐私政策里写明保存和删除方式。

## 8. 以“远程协助”为名操作你的设备

**识别信号**：让你安装远程控制软件、共享屏幕，或者打开某个网页“让系统自动检测”。

**为什么危险**：对方能看到并操作你设备上的一切，不只是 ChatGPT：浏览器里保存的其他登录状态、邮箱、支付 App 都暴露了。

**该怎么做**：拒绝任何远程控制。已经操作过的，卸载远程软件，修改重要账号的密码，退出所有设备。

## 9. 仿冒服务方的域名或兑换页

**识别信号**：链接和网站域名差一两个字母、换了后缀，或者经过短链接跳转；页面长得一模一样，但付款方式、客服联系方式不同。

**为什么危险**：仿冒页面收了钱不发货，更危险的是收集你提交的 Session 或其他凭证。

**该怎么做**：

- 自己在浏览器地址栏输入服务方的域名，而不是点聊天里的链接。
- 兑换页的域名应当写在服务方的条款或帮助中心里，提交前核对一次。以 KAI 为例，网站是 kaigpt.ai，兑换页只有 kaigpt.pro 一个；Session 只在卡密验证后于这个自有兑换页提交，不要通过私聊、邮件或工单把密码、验证码或 Session 发给任何人（包括客服）。
- 发现仿冒页面，截图后告知被仿冒的服务方。

## 已经被骗了怎么办

1. **保存证据**：聊天记录、付款记录、对方账号、链接。
2. **收回账号访问权**：按 [账号异常处理](account-anomaly-recovery.md) 改密码、退出所有设备、开启 MFA。
3. **申请支付平台介入**：通过付款记录联系支付平台，按其规则申诉；银行卡付款的，联系发卡行。
4. **报警或投诉**：金额较大时向当地公安机关报案；涉及经营者的，可以通过当地市场监管部门的 12315 渠道投诉。
