# ChatGPT 代充订单状态词典：每个状态是什么意思，下一步做什么

**最后核实：2026-09-29** · [← 返回总览](../README.md)

不同服务方的状态名称不一样，下表按常见含义归类，用来判断下一步，不代表任何平台的内部定义。**以你下单那家的订单页说明为准。**

## 状态对照表

| 状态 | 通常表示 | 你该做什么 | 不要做什么 |
|---|---|---|---|
| 待支付 | 订单已创建，还没收到付款 | 核对金额和收款方，只付一次 | 不要换个链接再付 |
| 支付确认中 | 支付渠道正在回传结果 | 等订单页更新，通常几分钟内 | 不要重复付款 |
| 已支付 | 付款已确认，等待后续步骤 | 按订单页提示完成下一步，保存订单号 | 不要以为已经开通了 |
| 卡密已发放 | 兑换码已生成 | 只在订单指定的兑换页验证 | 不要把卡密发到聊天里或公开 |
| 待提交 / 需要你操作 | 流程卡在你这一步 | 核对目标账号和兑换页域名后，在页面上完成提交 | 不要把任何凭证发给客服 |
| 处理中 | 服务方正在处理 | 以订单页写明的时间为准 | 不要重复下单，不要此时退出所有设备 |
| 人工复核 | 自动流程无法确认结果 | 保留凭证，等复核结果 | 不要在复核期间另找渠道再买一份 |
| 已完成 | 服务方记录开通成功 | 登录目标账号核对方案和续费日期，然后[收回访问权](what-is-session.md#用完之后怎么收回) | 不要跳过自己验收这一步 |
| 失败 | 本次没有开通成功 | 按订单页说明进入重试、复核或退款流程 | 不要马上重新下单 |
| 退款中 / 已退款 | 退款已发起或完成 | 按支付渠道的到账时间核对 | 不要在到账前追加付款 |

## 付了款但会员没生效

按顺序排查：

1. **看订单状态**：“已支付”只说明服务方收到了钱，不代表开通完成。
2. **看是不是“需要你操作”**：很多订单卡在等你完成页面上的一步。
3. **核对账号**：服务方开通的账号，和你现在登录的账号，邮箱和登录方式（Google、Apple、Microsoft、邮箱密码）是否一致。
4. **刷新方案状态**：退出 ChatGPT 网页版再登录，在设置里看当前方案。
5. **超过订单页写明的处理时间**，再通过服务方网站上的售后入口联系，附订单号。

## 重复付款怎么办

先分清是哪一种“两笔”：

| 情况 | 怎么判断 | 怎么处理 |
|---|---|---|
| 同一个订单付了两次 | 两笔付款对应同一个订单号 | 通过服务方售后入口提交两笔付款凭证，申请退回多付的一笔 |
| 下了两个订单 | 两个订单号 | 看第二个订单的状态；还没处理的，申请取消 |
| 服务方开通了一份，你又自己在 App 或网页上订阅了一份 | ChatGPT 设置里能看到自己的订阅 | 自己的那份在哪订的就在哪取消；已扣款的按对应平台的退款规则申请 |

服务方长时间不回应时，通过原支付记录联系支付平台，按其规则申请处理。

## 联系售后时准备什么

- 订单号、下单时间、付款时间；
- 当前状态和已经持续了多久；
- 打码后的付款截图（遮住与问题无关的个人信息）；
- 目标账号的邮箱和登录方式。

**联系客服时，不要附上密码、验证码或 Session。** 需要提交 Session 的步骤，只在服务方自有的兑换页上完成。

## 为什么“付款到完成”的时间不能直接比较

从付款到开通完成，中间可能包括等你完成提交、排队、人工复核等阶段。更有意义的口径是“完成页面要求的提交”到“开通完成”。看到某个渠道宣传“几秒完成”“平均多少秒”，先问清楚它从哪个时间点开始算、样本从哪里来。
