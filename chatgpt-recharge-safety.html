购买前的 7 项检查

01

核对服务主体

网站名称、域名、服务条款、隐私说明和联系方式应当一致。客服头像和“内部渠道”不能代替可验证的主体信息。

02

拒绝交出账号控制权

不要通过聊天、陌生短链、共享文档或远程控制软件发送密码、验证码、恢复码或长期有效登录凭证。

03

确认目标账号与现有订阅

记录当前登录邮箱和登录方式，检查账号是否已有订阅，避免充值到错误账号或重复购买。

04

分开核对支付与履约

支付成功只代表交易被确认，不代表会员已经生效。订单页应分别展示支付、提交、处理、完成或异常状态。

05

要求时效写明条件

时效说明应包含起算点、常规范围、可能延长的原因和异常处理方式。没有条件的“秒到账”不能作为安全证据。

06

核对退款路径

提前确认什么情况可退款、如何判断失败、退款回到哪里。通过原交易退款并保留状态记录，比口头承诺更容易核验。

07

区分会员与 API

ChatGPT Plus / Pro 与 OpenAI API 分开管理和计费。购买会员不会自动增加 API 调用余额。

到账快，也必须写清边界

  • 付款后保留订单号、金额和支付时间。
  • 会员未生效时先查订单，不要立即重复付款。
  • 确认失败后按订单规则通过原交易处理退款。

常见问题

不能一概而论。重点是服务身份、凭证边界、订单记录和退款路径是否可核验，而不是只看价格或宣传截图。

付款成功是否等于会员已经生效？

不等于。支付状态与会员履约状态是两个阶段，完成后还应在目标 ChatGPT 账号中确认当前套餐。
